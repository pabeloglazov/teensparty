# 3:16 TEENS — правила сайта teensparty.fun

Записано со слов Павла (ноябрь 2026). Менять только по его просьбе.

## Структура
- `teensparty.fun` — главная служения: показывает события. Каждое событие — своя страница с коротким адресом (`/xmas26`, `/fall26`), без слова Halloween.
- Главная = «заглушка» события с кнопкой; все детали — на странице события.
- Отметиться (check-in) с главной нельзя. Отметка — только внутри события и только для тех, кто зарегистрирован.
- Приложение на сайте не описываем; максимум — одна кнопка «Открыть приложение».
- Описание служения: «Подростковое служение русскоязычного потока SOL Church».

## Дизайн
- Единый стиль с приложениями: фон #0E0F12, карточки #15171B, акцент #FF8A3D, Inter для текста, Unbounded для заголовков, скруглённые карточки и кнопки.
- Christmas — рождественские краски (зелёный фон, красные кнопки, полосатая лента, снежинки, падающий снег), без фото: по событию ещё нет материалов.
- Билет на странице Christmas — «рождественский тикет».
- Кнопки в одном ряду/столбце — одинаковой длины.
- На телефоне фильтры (типы встреч) — одной линией с прокруткой пальцем, без переноса.
- Сетки и блоки выравниваются по одной ширине (места, счётчик).

## «Наши встречи» и «Галерея»
- Карточки унифицированы: одна картинка, ниже дата (`OCT 31, 2026`), название, тип; справа кнопка.
- Типы: Пати (все TEENS PARTY), Выезды, Встречи, Праздники. Сверху фильтр по типам.
- У прошедших событий — наклейка «Уже прошло»; она не должна закрывать название.
- Кнопка у прошедшего события всегда «Смотреть» и ведёт на страницу события (фото там). У будущего — «Зарегистрироваться».
- Если у события одно фото (Стенфорд) — «Смотреть» открывает его крупно.
- «Галерея» — отдельный блок, листается, фильтр по событиям.
- Фото выбираем те, где много людей.

## Страницы событий
- Прошедшее (TEENS PARTY 31.10): программа и фото остаются, в новом дизайне. Видео не показываем.
- Christmas (19 декабря, 6:00 PM, 5948 Pecan Ave, Orangevale): 50 мест; кнопки «Получить билет», «Зарегистрировать подростка · я родитель», после регистрации — «Зарегистрировать ещё кого-то»; блок «Как это было в прошлый раз» с крупной кнопкой «Смотреть фото» под фото.

## Small Group
- Карточка переворачивается по клику. На обороте — лидер и одна кнопка «Написать лидеру». Адрес группы на сайте не показываем.

## Языки
- RU / UA / EN на всех страницах, выбор запоминается.

- Small Group: карточка не переворачивается. На ней крупная кнопка «Написать лидеру» и рядом иконка телефона — по клику набор номера лидера.
- Описание служения в шапке: «Подростковое служение SOL RU», одной строкой.
- У заголовка «3:16 TEENS» анимация только при появлении (цифры выезжают, TEENS проявляется). Блика по контурному TEENS нет.
- При переключении языка ничего не должно прыгать: ни элементы баннера, ни сам переключатель языка (он всегда крайний справа), ни блоки ниже.

- Галерея на главной: листаются все фото, которые у нас есть (догружаются по мере листания), а не избранные.
- Сайт и Check-in дружат: событие создаётся в приложении 3:16 Check-in, регистрация со страницы события идёт в Check-in (`/app/join/?e=ID события`), счётчик мест на странице берётся из Check-in. Отдельных таблиц регистрации для новых событий не заводим. Christmas = событие `EMWJ5HI0V1X`.
- Блок «Хочешь на следующую?» на странице прошедшего события — в рождественском дизайне, тем же баннером, что на главной.
- Даты событий на сайте берём из Check-in (Стенфорд — OCT 17, 2026).
- Регистрация на TEENS PARTY остаётся на странице события (не уводим в приложение): лёгкая форма, один вопрос на экран. Данные сразу уходят в Check-in. Родитель обязателен; есть режим «я родитель»; своих не заставляем искать себя; билета с QR нет (QR на входе — позже).
- Страница прошедшего события, кнопки под фото в три ряда: «Показать все фото»; две кнопки «Оригиналы»; синяя кнопка Telegram в цветах Telegram.
- Заголовок «3:16 TEENS» на главной — во всю ширину: на компьютере одной строкой, на телефоне двумя строками, каждая во всю ширину.
- Запись с сайта: сервер сам сверяет человека с базой (умное сравнение); кнопки «Уже записан? Проверить запись» нет.
- Страница события на компьютере: билет справа тянется по высоте до нижней линии таймера.
- Регистрация: на билете и на сайте одна кнопка «Зарегистрироваться». Первым экраном формы — выбор «Я подросток / Я родитель», дальше вопросы по выбранному.

- Ссылка «Уже есть билет? Проверить» стоит на лицевой стороне билета под кнопкой регистрации всегда, в том числе когда билет уже есть.
